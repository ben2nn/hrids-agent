# 图片上传与显示功能说明

## 功能概述

Web 端现已支持图片上传、预览和 AI 理解功能。用户可以通过附件按钮上传图片，图片会显示在消息气泡中，AI 可以通过 `file_read` 工具读取图片内容。

## 使用方法

### 1. 上传图片

1. 点击输入框右下角的 **📎 回形针图标**（附件按钮）
2. 在文件选择对话框中选择图片文件（支持多选）
3. 支持的图片格式：
   - JPG/JPEG
   - PNG
   - GIF
   - WebP
   - SVG
   - BMP
   - TIFF
   - ICO

### 2. 图片预览

- **上传中**：显示上传进度提示
- **上传成功**：在输入框上方显示 64×64 缩略图网格
- **悬停操作**：鼠标悬停在缩略图上可以看到删除按钮
- **移除图片**：点击删除按钮可以移除已上传的图片

### 3. 发送消息

- 上传图片后，可以输入文字描述（可选）
- 点击发送按钮，消息会包含图片引用（`@filename.jpg`）
- 图片会显示在用户消息气泡上方，最大尺寸 200×200
- 点击图片可以在新标签页中查看原图

### 4. AI 理解图片

图片上传到工作目录后，AI 可以通过以下方式理解图片内容：

1. **文件读取**：AI 使用 `file_read` 工具读取图片文件
2. **Vision API**（未来支持）：直接将图片传递给支持视觉的 LLM 模型

## 技术实现

### 前端

- **InputBar.tsx**：图片选择、上传、缩略图预览
- **MessageItem.tsx**：用户消息中显示图片
- **gateway.ts**：`getImageUrl()` 生成图片访问 URL，`isImageFile()` 判断文件类型
- **types.ts**：`DisplayMessage` 的 user 类型新增 `images?: string[]` 字段

### 后端

- **server.ts**：新增 `GET /sessions/:id/image?path=` 端点
  - 直接返回图片二进制数据
  - 支持 MIME 类型自动识别
  - 带 `Cache-Control` 缓存头
  - 路径安全检查（禁止访问工作目录之外的文件）
  - 文件大小限制：20MB

## 注意事项

1. **文件大小限制**：
   - 单个文件最大 50MB（上传）
   - 图片预览最大 20MB（显示）

2. **安全性**：
   - 图片上传到会话的工作目录
   - 后端强制路径安全检查，禁止访问工作目录之外的文件
   - 支持 Gateway 鉴权（Bearer Token）

3. **性能优化**：
   - 图片缩略图使用本地 `objectURL` 预览，无需等待上传完成
   - 后端图片端点带 `Cache-Control` 缓存头，减少重复请求
   - 虚拟滚动支持大量消息中的图片显示

4. **浏览器兼容性**：
   - 使用标准 `<input type="file">` 和 `URL.createObjectURL()`
   - 支持所有现代浏览器（Chrome、Firefox、Safari、Edge）
