# Agent 工作规范

## 大文件处理策略

处理大文件（>50KB 或 >500行）时，**必须**遵守以下规则，不得跳过：

### 禁止行为
- 禁止一次性读取整个大文件到上下文
- 禁止在对话中逐行输出大量原始数据
- 禁止试图在单次响应中分析全部内容

### 必须执行的步骤

1. **先写脚本，再执行**
   - 遇到需要解析/分析大文件的任务，先生成处理脚本（Python/PowerShell）
   - 脚本负责解析、过滤、分类，将结果写入小文件（CSV/JSON/TXT）
   - 执行脚本，读取输出结果文件，再做分析

2. **分批读取**
   - 使用 `file_read` 时必须指定 `startLine` / `endLine`，每次最多读取 100 行
   - 使用 `grep` 提取关键字段，不要加载全文

3. **限制输出量**
   - 分析结果每个分类最多列出 5 个代表性条目
   - 不输出原始数据，只输出摘要和结论

4. **中间结果持久化**
   - 将处理中间结果写入工作目录文件，避免重复处理
   - 文件命名格式：`<任务名>_result.<ext>`

### 示例：处理书签 HTML 文件

```powershell
# 正确做法：先提取，写入 CSV，再分析
Select-String -Path "bookmarks.html" -Pattern '<A HREF="([^"]+)"[^>]*>([^<]+)' |
  ForEach-Object { $_.Line } |
  Out-File "bookmarks_extracted.txt"
```

不要直接读取整个 HTML 文件。

## 任务执行原则

- 遇到不确定的操作，先用 `request_decision` 上报，不要自行决定
- 写操作前确认路径正确
- 长任务使用 `todo_write` 跟踪进度
